四、换了 WiFi / IP 变了怎么办 难度 ⭐

IP 是写进二维码图片里的，换网络后必须重刷一次，否则手机扫码会指向旧地址。

  1. 查新 IP：命令行执行 ipconfig，看「IPv4 地址」。
  2. 用新 IP 重启后端（把下面命令里的 IP 换掉）。
  3. 调一次刷新接口，全部二维码（当前 108 个）会按新 IP 重新生成，商品和链上数据不动。
  4. 若同时换了虚机网段，还要改 backend/fisco/config.toml 的 peers。
# 1) 重启后端（在 backend 目录下，把 IP 换成新的；真链模式不要带 --fisco.enabled=false）
C:\Users\Lenovo\.jdks\openjdk-22\bin\java.exe -jar target\goods-evidence-1.0.0.jar ^
  --server.port=8080 ^
  --app.public-base-url=http://新IP:8080

# 2) 重刷全部二维码（PowerShell）
$t = (Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/auth/login `
      -ContentType "application/json" -Body '{"username":"ent","password":"123456"}').data.token
Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/product/refresh-qr `
      -Headers @{ Authorization = "Bearer $t" }
注意：已经打印在纸上或发给别人的旧二维码图片不会自动变，需要重新导出。会场不便开虚机时，在启动命令里补一个 --fisco.enabled=false 即可切回 Mock 链，业务流程照常演示（但论文/答辩口径要说明是模拟链）。
